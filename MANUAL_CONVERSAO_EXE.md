# GUIA DE CONVERSÃO PARA EXECUTÁVEL WINDOWS (.EXE) - NANUCLOUD

Consulte o manual detalhado em `/docs/MANUAL_CONVERSAO_EXE.md` ou execute:
1. `build_windows_exe.bat` para compilar o executável com Electron Builder.
2. `INICIAR_SISTEMA.bat` para iniciar o servidor local com base de dados SQLite padrão (`data/nanucloud.sqlite`).
