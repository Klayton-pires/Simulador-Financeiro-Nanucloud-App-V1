Matriz Fiscal & Legislações Aduaneiras

Tabela de referência para parametrização dos cálculos em conformidade com as regras fiscais dos países suportados.

🇦🇴

Angola (AGT)

CIVA / Pauta Aduaneira OMA
  • • IVA Geral: 14% (Regime Geral)
  • • IVA Cesta Básica: 5% (Alimentos Essenciais)
  • • IVA Simplificado: 7%
  • • Retenção Serviços: 6.5% (Art. 67º CIVA)
  • • Imposto Industrial: 25% (Geral) / 35% (Banca/Seguros)
  • • Direitos Aduaneiros: 2% a 70% conforme NCM/SH
🇵🇹

Portugal (AT)

Código do IVA / CIRS / CIRC
  • • IVA Normal: 23% (Continente)
  • • IVA Intermédio: 13%
  • • IVA Reduzido: 6%
  • • Retenção Cat. B: 20% a 25%
  • • IRC Geral: 21% (+ Derrama Municipal)
🇲🇿

Moçambique (ATM)

Regulamento do IVA / IRPC
  • • IVA Geral: 16% (Atualizado Decreto 2023)
  • • Retenção Serviços: 20%
  • • IRPC: 32% (Taxa Padrão)
🇨🇻

Cabo Verde (DNRE)

CIVA / IRPC
  • • IVA Geral: 15%
  • • Retenção Serviços: 20%
  • • IRPC: 22%
🇧🇷

Brasil (Receita Federal)

ICMS / PIS / COFINS / IRPJ
  • • ICMS Médio: 18% a 20.5%
  • • Retenção IRRF Serviços: 1.5% a 4.65%
  • • IRPJ + CSLL: Lucro Real / Presumido / Simples
🌐

Padrão OMA / Incoterms 2020

Comércio Transfronteiriço
  • • Base CIF: FOB + Frete + Seguro
  • • Valor Tributável: CIF + Direitos Pautais
  • • Dupla Tributação: Convenções Bilaterais
